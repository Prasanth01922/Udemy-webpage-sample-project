# Udemy Webpage Clone

A responsive **Udemy homepage clone** built using **HTML, CSS, and Flexbox**.
This project showcases my front-end development skills by recreating a modern e-learning platform interface with a clean and structured layout.

## Features

* Responsive webpage layout
* Navigation bar design
* Hero/banner section
* Course cards section
* Footer section
* Built using Flexbox for alignment and spacing
* Clean and user-friendly UI

## Tech Stack

* **HTML5**
* **CSS3**
* **Flexbox**

 

## Purpose

This project was created to improve my skills in:

* Front-end web development
* Layout design
* Responsive styling
* Flexbox positioning
